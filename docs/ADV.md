# Adyen Document Viewer

Generic non-technical information.

## What is it?

Adyen Document Viewer (ADV for short) displays documents generated within Adyen inside any website. It turns generated
data into human readable pages with headings, links, lists, etc.

## Who is it for?

It can be used both by internal teams that need to show document, such as Terms of Service in Onboarding,
or external organizations integrated with Adyen that need to show Adyen-generated data. It's a visualization
layer to facilitate document viewing on the web.

## A distributed NPM library

`@adyen/adyen-document-viewer` is distributed as an npm library. It is publicly available and open source on Github.
This means it's a using a well known distribution method, allowing merchants to integrate Adyen contracts within their
websites in a simple and straightfoward way.
